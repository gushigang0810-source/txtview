4.简述废塑料炼油的优点和缺点
答：优点是通过资源化利用减少了填埋和焚烧带来的污染和温室气体排放，炼油技术门槛比较低，补充了能源供应，相比直接燃烧，实现了碳循环。 缺点是其热解废物处理不当会造成二次污染。 产品热值低，若进一步提纯会增加成本，连续生产稳定性不高，热解过程仍会排出二氧化碳。
